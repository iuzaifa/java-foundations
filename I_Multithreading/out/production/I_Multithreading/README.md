

###  **1. What is a Thread?**

A **thread** is the **smallest unit of execution** in a program.

In Java, a thread is like a **separate path of execution**. A single program (process) can have **multiple threads** running different tasks **at the same time**.

>  Example: If a program is like a road, a thread is a lane where cars (tasks) can move independently.

---

###  **2. What is Multithreading?**

**Multithreading** is a technique where **multiple threads** run **concurrently** in a single program to perform different tasks **simultaneously**.

>  It helps in executing multiple tasks at the same time (like loading a webpage while playing music).

---

###  **3. Why use Multithreading?**

We use multithreading to:

*  **Increase performance** by doing multiple tasks in parallel
*  **Improve responsiveness** (e.g., UI doesn’t freeze)
*  **Utilize CPU resources better**
*  Handle **multiple users or requests** efficiently (e.g., in servers or games)
